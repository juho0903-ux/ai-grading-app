# 국어 서·논술형 답안 작성 연습 v3

이 버전은 원자료의 지문과 문항 문구를 화면에 직접 제시하도록 수정했습니다.

## 구조
- 1세트: 사회적 촉진·사회적 억제
- 2세트: 정전기
- 3세트: 인공 지능과 예술
- 각 세트 안에 서·논술형 1, 2, 3
- 복습할 내용 탭

## 배포
GitHub 저장소에 다음 파일을 올리세요.

- app.py
- requirements.txt
- .streamlit/config.toml

Streamlit Community Cloud에서 Main file path를 `app.py`로 지정하면 됩니다.
